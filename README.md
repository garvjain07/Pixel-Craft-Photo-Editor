# PixelCraft - Professional Photo Editor

A powerful, browser-based photo editor built with HTML, CSS, and JavaScript using Fabric.js.

## ✨ Features

- **Basic Editing** — Crop, Resize, Rotate, Flip
- **Adjustments** — Brightness, Contrast, Saturation, Hue, Blur, Noise, Temperature
- **Filters** — 15+ preset filters (Grayscale, Sepia, Vintage, HDR, etc.)
- **Drawing Tools** — Brush, Eraser, Shapes (Rectangle, Circle, Line, Arrow, Triangle)
- **Text Tool** — Custom fonts, colors, shadows, letter spacing
- **Stickers** — 120+ emojis across 4 categories
- **Watermark** — Single or tiled watermark with opacity control
- **Frames** — 6 frame styles (Simple, Rounded, Shadow, Polaroid, Neon, Double)
- **Background Remover** — Color-based with tolerance and eyedropper
- **Layers Panel** — Add, toggle visibility, delete layers
- **History** — 50-step Undo / Redo
- **Export** — PNG, JPEG, WebP, BMP with quality control
- **Dark / Light Mode** — Full theme support
- **Keyboard Shortcuts** — Full keyboard workflow support
- **Mobile Responsive** — Works on tablets and phones

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `V` | Select tool |
| `H` | Hand / Pan tool |
| `B` | Brush tool |
| `E` | Eraser tool |
| `T` | Text tool |
| `C` | Crop tool |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + S` | Save / Export |
| `Ctrl + O` | Open image |
| `Delete` | Delete selected object |
| `+` / `-` | Zoom in / out |
| `0` | Zoom to fit |

## 🌐 Deploy on Vercel

1. Fork or clone this repository
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click **"Add New Project"** → Import this repo
4. Leave all settings as default (Framework: Other)
5. Click **Deploy** — done! ✅
